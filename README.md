# 人像工坊

给图片创作准备可以直接粘贴的中文提示词。人物和画幅是默认值，不用每次再选。

默认人物是：绝美23岁东亚成年女性，身材匀称丰满，上围明显自然丰满圆润、富有真实体量感，配合纤细腰部，胸腰差明显，但不夸张、不假体感。

默认画幅是 9:16 竖幅。

## 怎么用

1. 选一个类别：美女写真、内衣写真、纪实抓拍。打开时停在美女写真。
2. 点一个主题。每个主题有一组不同的变体。
3. 点「复制这条」，或点「复制整组」。整组的格式和现有提示词文件一样，带编号和正文。

想换人物或画幅时，打开右上角「设置」。改完之后，所有主题都会跟着变。点「恢复默认」就回到上面那句人物和 9:16。

最近复制过的条目留在本机，不上传。

## 视觉

界面只用一种暖纸色、宋体标题和朱砂色按钮。最早的页面是浅绿色的密集表单，后来几轮改成暖色编辑风，中间又加上过立体人像，所以每一轮看起来都不一样。这一版把立体人像拿掉，只保留暖色编辑风，让页面回到「选主题、读提示词、复制」。

```bash
npm install
npm run dev
```

浏览器打开 http://127.0.0.1:5173 。数据只在这台浏览器里。
