# 人像工坊

在手机或电脑上，看着一张真实人像，把场景、衣服、光线和景别收成一份可以复制的创作简报。照片是风格参考，不会跟着选项变化。没选的内容不会进复制结果。

数据只存在这台设备的浏览器里，不上传，也不调用生图服务。

## 环境

需要 Node.js 22 或 24。安装依赖时需要联网，安装完成后预览、保存和复制都可以离线使用。

## 启动

macOS 可以双击 `start.command`，然后打开 <http://127.0.0.1:5173>。保持终端窗口开着，按 Control+C 停止。脚本会优先使用本机 nvm 里的 Node.js，不改系统配置。

也可以自己启动：

```bash
npm ci
npm run dev
```

开发服务器只监听本机 `127.0.0.1`，不会暴露到局域网。

## 构建

```bash
npm run build
npm run preview -- --port 5173
```

`npm run build` 会先做 TypeScript 检查，再把站点输出到 `dist/`。这是一套静态文件，放到任意静态网站的根目录就能访问。用手机浏览器打开部署后的地址即可。

请用同一个浏览器、同一个地址和端口，才能看到同一份本地历史。`localhost` 和 `127.0.0.1` 的存储不通用。

如果要临时在同一 Wi-Fi 的手机上打开本机预览，可以：

```bash
npm run preview -- --host 0.0.0.0 --port 5173
```

用完就停。不要把对局域网开放当成默认方式。

## 怎么用

1. 上面（宽屏在中间）是一张真实人像，标着「风格参考，不会随选项变化」。
2. 四个方向：影棚侧光、冷调特写、黄昏户外、街角暖光。空白时点一下就写入一组文字，并换上对应的照片。已经有文字时，会先给你看改动，确认后才换。
3. 也可以直接点场景、服饰、光线、取景、姿势、人物。只选「裙装」或「海边」也可以。
4. 底部一直有「简报 / JSON」和「一键复制」。复制成功后会记入历史。剪贴板不可用时，可以手动选择文字或下载。
5. 「历史」里可以搜索、收藏，并按当时的原文再次复制。从记录恢复时会新建副本。
6. 「方案」用来保存和打开命名方案。草稿会自动保存。
7. 「设置」里可以导出全部数据，或从备份恢复，也可以查看每张参考照片的编号和许可。

以前更细的参数如果已经存在本地存档里，打开后仍会出现在「已选」和复制结果中，不会被清掉。新的主界面不再铺开那些细项。

## 开发

```bash
npm test
npm run test:e2e
npm run build
```

端到端测试使用本机 Google Chrome，并使用隔离的浏览器存储。

```text
src/catalog.ts    参数目录
src/domain.ts     稀疏导出、校验、冲突、锁定与历史
src/references.ts 四张参考人像和它们对应的文字
src/storage.ts    IndexedDB 与下载
src/App.tsx       界面
src/styles.css    视觉
```

照片来源和许可见 [资产说明](docs/资产说明.md)。参数格式见 [参数协议](docs/参数协议.md)。当前做到哪一步见 [实现状态](docs/实现状态.md)。
