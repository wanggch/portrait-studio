# 人像工坊

在手机或电脑上，把人像构思收成一份可以复制的创作简报。人物、衣服、姿势、场景、镜头和光线都可以只选一部分；没选的内容不会进复制结果。预览是本地的程序化模特，用来看构图，不是最终成片。

数据只存在这台设备的浏览器里，不上传，也不调用生图服务。

## 环境

需要 Node.js 22 或 24。安装依赖时需要联网，安装完成后预览、保存和复制都可以离线使用。

## 启动

macOS 可以双击 `start.command`，然后打开 <http://127.0.0.1:5173>。保持终端窗口开着，按 Control+C 停止。脚本会优先使用本机 nvm 里的 Node.js，不改系统配置。

也可以自己启动：

```bash
npm ci
npm run dev
```

开发服务器只监听本机 `127.0.0.1`，不会暴露到局域网。

## 构建

```bash
npm run build
npm run preview -- --port 5173
```

`npm run build` 会先做 TypeScript 检查，再把站点输出到 `dist/`。这是一套静态文件，放到任意静态网站的根目录就能访问。用手机浏览器打开部署后的地址即可。

请用同一个浏览器、同一个地址和端口，才能看到同一份本地历史。`localhost` 和 `127.0.0.1` 的存储不通用。

如果要临时在同一 Wi-Fi 的手机上打开本机预览，可以：

```bash
npm run preview -- --host 0.0.0.0 --port 5173
```

用完就停。不要把对局域网开放当成默认方式。

## 怎么用

1. 打开就能看到四个方向：窗边的午后、海风来信、城市漫步、纯粹肖像。点一下会先列出将要改动的参数，确认后才写入。
2. 也可以直接点「人物、服饰、场景」这些分组，用圆角按钮选具体项。常用项在外面，其余在「更多细节」里。不需要下拉框，选参数也不会再弹窗。
3. 只选大类也可以，例如只选「裙装」或「海边」。展开细分不会自动选中。
4. 中间（手机上在最上面）是模特。单指旋转，双指缩放。自由观察不会改掉拍摄机位；点「设为拍摄机位」才会记下来。
5. 底部一直有「简报 / JSON」和「一键复制」。复制成功后会记入历史。剪贴板不可用时，可以手动选择文字或下载。
6. 「历史」里可以搜索、收藏、比较，并按当时的原文再次复制。从记录恢复时会新建副本，不覆盖当前方案。
7. 「方案」用来保存、打开、复制和比较命名方案。草稿会自动保存。
8. 「设置」里可以调预览质量、导出全部数据，或从备份恢复。清理浏览器数据会丢掉本地内容，请定期导出。

锁定后的参数不会被模板或随机覆盖。随机和自定义模板在编辑区底部的「保存模板、随机组合」里，应用前同样先看变化。

## 开发

```bash
npm test
npm run test:e2e
npm run build
```

端到端测试使用本机 Google Chrome，并使用隔离的浏览器存储。

```text
src/catalog.ts    参数目录、姿势和内置方向
src/domain.ts     稀疏导出、校验、冲突、锁定、模板与历史
src/storage.ts    IndexedDB 与下载
src/Studio.tsx    程序化人物、场景和独立摄影机
src/App.tsx       界面
src/styles.css    视觉
```

## 模型边界

这是可以交互的程序化造型参考，不是已经采购好的高质量数字人。衣服和头发是几何变体，坐卧可能穿插，妆容和细纹只进入文字。自定义写法会保留在简报里，但不能当成 3D 已经准确还原。

更细的差距见 [实现状态](docs/实现状态.md) 和 [资产说明](docs/资产说明.md)。参数格式见 [参数协议](docs/参数协议.md)。
