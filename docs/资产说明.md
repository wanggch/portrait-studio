# 资产来源与预览能力

当前运行资产全部由 `src/Studio.tsx` 的 Three.js 几何构造生成，没有外部照片、字体、付费人体模型或不明授权的服装文件。项目未采购素材，也不依赖远程 CDN。应用依赖包授权见各包附带的 LICENSE；这不改变依赖自身授权。

## 原创程序化资源

| 类别         | 实际实现                                               | 限制                                                            |
| ------------ | ------------------------------------------------------ | --------------------------------------------------------------- |
| 成年女性模特 | 椭球体、旋转曲面、层级关节构成的风格化人物             | 非写实网格，无精细面部变形；3 种体型为比例近似                  |
| 发型         | 长直、短发、波波头、卷发、马尾、盘发 6 个构造方向      | 几何发束，不是毛发物理系统                                      |
| 服饰         | 上装、裙装、裤装、连体与泳装轮廓；外套、鞋袜变体       | 多个变体共享基础曲面，不能把界面文字条目等同独立高质量模型      |
| 饰品         | 耳饰、项链、腕饰、发饰、眼镜、帽子、腰带、围巾、包等   | 依附层级挂点，精细戒指当前只导出                                |
| 动作         | 24 个姿势预设入口，7 类姿态及若干关节变化              | 刚性层级关节，无蒙皮、IK 或布料求解；复杂姿势不是摄影级准确人体 |
| 场景         | 影棚、窗边、客厅/咖啡馆近似、街道、海边、树林          | 房间共用简化窗景，非完整场景模型                                |
| 支撑物/道具  | 椅子、沙发、床、桌、墙、栏杆，以及书、杯、花束、伞、球 | 基础几何构成；道具握持为挂点近似                                |

## 参数对预览的影响

- 实时：已支持的主色、肤色、发色、身体方向、镜像、摄影机、灯光方向/强度/色温。
- 近似：体型、发型、服装、姿势、支撑物、饰品与场景。
- 仅导出：面部细节、妆容、表情、情绪、精细图案、点缀、真实景深、复杂摄影风格及未映射的自定义内容。
- 自定义文字不保证对应几何；预览保持可用的默认或近似外观，不将该外观写入参数。

## 后续高质量资产替换条件

如需达到需求文档中正式 A+B 造型展示的质量，应先确定素材预算与美术标准，再引入授权清晰的统一骨骼 GLB、服装和发型，建立逐件体型/姿态兼容矩阵。不能直接用任意网上模型替换后宣称换装和姿势兼容。
