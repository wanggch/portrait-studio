# 资产来源

## 可旋转的立体人像

中间的头像是 Lee Perry-Smith 的三维扫描「Infinite, 3D Head Scan」，来自 Infinite Realities / triplegangers.com。许可为 [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)。本仓库使用的是 three.js 示例里随许可一起分发的 glTF 和贴图，文件在 `src/assets/portrait/`，运行时不再请求外链。

这是成年男性的头部扫描：皮肤和五官来自真实扫描，带颜色贴图和法线贴图。扫描时双眼是闭合的。没有长发，没有衣服，也没有身体。界面上的选项不会驱动它换姿势或换衣服。贴图是 three.js 随模型分发的 1024×1024 版本。
