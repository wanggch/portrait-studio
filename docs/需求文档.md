# 人像创作配置台：产品需求文档

- 版本：v1.2 需求基线
- 日期：2026-11-12
- 状态：核心方向已确认；下述未标注为用户确认的细节均为建议规格，实施前按资产与性能验证调整。
- 目标用户：个人、本地使用。

## 1. 已确认的产品边界

1. 网页以成年女性 3D 模特为中心，辅助配置图片创作参数。
2. 3D 达到 A+B：构图参考，以及服装、发型、饰品的可视化展示；不要求照片级人物或实时布料模拟。
3. 参数体系完整，一次交付本文件约定的功能，不以精简版代替。
4. 当前支持一键复制参数；未来可接本地 AI Agent，当前不实现直接调用。
5. 不绑定现有提示词 Skill，使用独立、可扩展的输入协议。
6. 不做账号、多人协作、云端同步、在线素材商城、图片生成服务。
7. 参数全部可选，允许只选择部分参数或某个大类；未选择的参数不出现在一键复制内容中。不强制完成任何配置流程。

“完整”指约定功能闭环和参数维度齐备，不指无限服装、无限姿势或任意参数都能精确重建为 3D。资产库必须有明确交付清单。

## 2. 产品目标与主要流程

将构思转换为可视化、可检查、可复用的创作方案，再以结构化参数交给用户选择的提示词工具。

主流程：新建或载入方案 → 按需选择任意参数或大类 → 预览已选内容与相关冲突 → 一键复制。人物、造型、姿势、场景、摄影与光线均可跳过。

辅助流程：模板起步、方案复制、局部锁定随机、方案对比、历史恢复、导入导出。

## 3. 页面与交互结构

### 3.1 布局

- 顶栏：方案名称、新建、打开、保存、复制方案、撤销、重做、设置。
- 左栏：人物、服饰、饰品道具、姿势、场景、摄影、光线风格、故事与输出八组参数。
- 中央：3D 工作区、取景窗口、视角工具和对象选择。
- 右栏：参数摘要、锁定列表、冲突提示、自然语言简报、结构化参数、一键复制。
- 底部抽屉：姿势、服装、发型、场景模板图库；可折叠。

### 3.2 通用交互

- 字段支持搜索、分类筛选、恢复默认、自定义文本；色彩支持色板与自定义色值。
- 多选字段明确显示可多选；互斥项使用单选。
- 大类可直接选中，无须选择下级。例如选择“裙装”即可，不必继续指定裙型、裙长、颜色或材质；展开分类仅用于浏览，不等于选中。
- 每项可清除，整个模块可清空；清除后立即从复制预览中移除。选择父类不自动勾选全部子项。
- 进阶字段可折叠，但不能因折叠而丢失设置。
- 每个字段标明“实时预览”“近似预览”“仅导出”；近似预览需能查看差异说明。
- 已选择但当前无对应资产的内容保留在方案内，不静默删除或偷偷替换。
- 删除或切换父项导致子项失效时，提示受影响内容，提供取消操作。
- 表单与预览双向关联：选中饰品可定位对应配置；不要求自由拖动所有物体。

### 3.3 观察视角与摄影机

- 检查模式支持旋转、缩放、平移、正面/背面/侧面/俯视快捷视角。
- 拍摄模式使用独立摄影机，显示画幅、安全框、三分线和人物裁切情况。
- 自由观察不改变导出的拍摄机位。
- “将当前视角设为拍摄机位”明确同步两者；“回到拍摄机位”只改变观察视角。
- 快速聚焦全身、面部、上装、下装、饰品。

## 4. 参数体系

### 4.1 人物

| 字段组 | 参数                                             |
| ------ | ------------------------------------------------ |
| 身份   | 人物卡、角色名称、明确成年年龄或年龄段、外貌描述 |
| 面部   | 脸型、五官特点、肤色、皮肤特点                   |
| 身形   | 身高、整体体态、体型预设、肩腰臀比例、肌肉感     |
| 发型   | 长度、直卷、刘海、扎发方式、发色                 |
| 妆容   | 妆容类型、浓淡、唇色、眼妆                       |
| 表情   | 平静、微笑、专注、惊喜等及程度                   |
| 气质   | 温柔、自信、清冷、活泼等，可多选并指定主气质     |

人物必须明确成年。年龄数值不保证在 3D 中精确呈现。精细五官与比例字段在无对应变形资产时仅导出；不承诺任意滑杆均可驱动人物网格。

### 4.2 服装

采用“穿搭结构 + 单品槽位 + 类目级联 + 属性面板”，避免用一棵树表达所有关系。

- 穿搭结构：上下装、连衣裙、连体装、成套装束、泳装等。
- 单品槽位：内搭、上装、下装、连体主装、外套、袜类、鞋履。
- 服装属性：类型、版型、领型、袖型、长度、腰线、开合方式、穿着状态。
- 材质属性：棉、针织、牛仔、缎面、皮革等；表面粗糙度与光泽可使用预设。
- 色彩图案：主色、辅色、图案、纹理比例；自定义文字描述。
- 点缀：刺绣、蕾丝边、蝴蝶结、纽扣、褶皱、流苏、金属扣等。
- 穿着方式：扎入、自然垂落、卷袖、外套敞开或扣合等。

示例级联：下装 → 半身裙 → A 字裙 → 裙长/腰线/材质/颜色。不同单品只展示适用字段。

服装结构型参数仅在有匹配模型时切换几何；颜色、已支持材质可实时更新；细节描述可仅导出。界面必须区分“当前服装外观”和“期望服装描述”。

### 4.3 饰品、附件与道具

- 佩戴饰品：耳饰、项链、手链、戒指、腕表、发饰、眼镜、帽子。
- 穿搭附件：腰带、围巾、包等。
- 互动道具：书、杯子、花束、雨伞、运动器材等。
- 属性：类型、颜色、材质、大小预设、佩戴侧、绑定位置。
- 道具关系：左手持有、右手持有、双手持有、桌面放置、地面放置等。
- 不支持对应绑定的自定义道具仅导出，不能显示为已在模型中准确装配。

### 4.4 姿势与动作

- 一级姿态：站、坐、蹲、跪、卧、行走、运动。
- 二级姿态：侧站、倚墙、椅坐、地坐、仰卧、侧卧、俯卧等；“躺”归入“卧”。
- 细化参数：身体朝向、头部朝向、视线目标、手臂姿态、手部任务、腿部姿态。
- 动作阶段：刚坐下、即将起身、转头中、行走中短暂停顿等。
- 支撑关系：脚与地面、臀部与座面、手肘与桌面等。
- 状态：动作幅度、重心方向、左右镜像。

以静态骨骼姿势预设为主，提供资产允许的头部朝向、身体转向等有限调整；任意骨骼编辑、完整 IK 编辑器不在本范围。行走和运动展示选定瞬间，不要求动画播放。

身体朝向、头部朝向、视线方向、摄影机朝向独立存储。

### 4.5 场景与环境

- 场景分类：室内、城市、自然、影棚。
- 地点：公寓、咖啡馆、街道、海边、树林等。
- 空间结构：窗边、走廊、露台、楼梯、开放空间等。
- 支撑物：椅子、沙发、桌子、墙、栏杆、床等。
- 环境：季节、时间、天气、风力、背景复杂度、远景元素。
- 动态意图：风吹碎发、落叶、远处人流等，仅作为静态参考或导出描述。
- 位置关系：人物距背景、与支撑物的相对位置。

场景采用有限低复杂度 3D 预设与环境背景。选择预设外的“咖啡馆”等地点时可使用近似参考场景，但必须保留实际地点描述并提示差异。

### 4.6 摄影与构图

- 景别：面部特写、胸像、半身、七分身、全身、环境人像。
- 机位：水平环绕角、俯仰角、相机高度、目标点、拍摄距离。
- 镜头：35/50/85/105mm 预设及自定义；定义固定传感器规格，建议全画幅 36×24mm，确保焦段与视角转换一致。
- 画幅：1:1、3:4、4:5、9:16、16:9及自定义比例。
- 构图：居中、三分法、对称、留白方向、人物画面占比。
- 景深：清晰、适度虚化、浅景深；对焦目标。
- 镜头倾斜：默认水平，允许设置。

景别为构图意图，焦段与距离共同决定实际画面；自动取景应说明将调整哪些字段，不静默改变锁定项。

### 4.7 光线与风格

- 光源：自然光、窗光、棚灯、街灯、混合光。
- 主光：方向、强度、软硬、色温。
- 辅助：补光、轮廓光、环境亮度。
- 视觉：写实、电影感、胶片、时尚编辑、插画等风格描述。
- 色调：自然、暖色、冷色、低饱和等。
- 质感：自然肤质、颗粒、柔焦等。

主光方向、强度、颜色等实时预览；虚化与柔光可近似预览；风格、皮肤质感等不保证由 3D 精确复现。

### 4.8 故事、约束与输出

- 创作主题、人物正在做的事、瞬间状态、情绪意图。
- 用途：头像、写真、封面、社交配图等。
- 必须包含、避免出现、自由补充。
- 输出意图：单个方案、多套差异化创意、同人物同造型系列。
- 期望数量：由用户填写，不继承任何现有 Skill 的固定数量。
- 允许变化维度、锁定维度、输出语言。

网页只定义输出意图和约束，不在本范围内自动生成多套提示词。数量与模式作为下游工具的输入。

## 5. 参数状态与优先级

每个字段包含：稳定字段标识、值、状态、是否锁定、来源、预览支持级别。

- 未设置：用户未选择，不进入复制内容，不输出空值、占位或“未设置”等文字。
- 自动：仅在用户主动选择“交由下游决定”时记录并导出，不作为未选字段的默认状态。
- 指定：用户给定值。
- 不使用：明确排除该元素；例如不戴项链。
- 锁定：独立布尔标记，约束随机、模板应用和后续生成；不允许锁定无语义的未设置值。

优先级：用户锁定项 > 用户明确指定项 > 用户选择的模板默认值 > 下游工具默认值。发生冲突时不靠优先级静默抹掉参数，而是提示用户处理。

### 5.1 选择粒度与预览默认值

- 支持模块、分类、具体值的稀疏配置；只选择大类时，按大类输出，不补齐子项。
- 选中具体子项时，可保留理解该子项所必需的父级路径，例如“服装 → 下装 → 半身裙”；这不代表用户额外指定了其他同级或下级属性。
- 3D 初始化所需的默认模特、衣服、站姿、场景、灯光与摄影机仅是展示默认值，不自动成为用户创作参数。默认模特用于成年女性预览，也不自动输出年龄、体型等默认描述。
- 单独设置服装颜色等属性时，不强迫选定具体款式；预览可借用默认服装展示颜色，但不能把该服装款式加入复制内容。
- 通过用户主动应用模板或确认随机方案产生的参数视为已选，应用前说明将加入哪些项；仅浏览、悬停预览不算选择。
- 为预览自动补充的椅子、背景或灯光等只属展示依赖，未经用户确认不导出。

## 6. 核心功能规格

### 6.1 一键复制

提供一个主按钮和格式切换：

1. AI 创作简报：默认格式，包含创作目标、自然语言分组参数、锁定与可变项、避免项。
2. JSON 参数：机器可读，字段名称稳定，仅含已选创作参数；协议版本只存入项目文件。

复制前显示完整内容；成功或失败均有反馈。剪贴板不可用时提供可选中文本框和下载文件，不假报成功。

创作简报仅整理用户已选信息及其已有关系，不为凑成完整句子擅自添加人物、服装、动作、支撑物、场景或机位。未选模块整段省略；未选字段、空数组、空对象、null 和默认占位均不输出。明确选择的“不使用”仍应输出，因为它是用户约束而非未选。

复制示例：用户只选择“海边”和“裙装”，内容仅为：

```text
场景：海边
服装：裙装
```

不得额外出现默认年龄、默认站姿、裙长、颜色、机位、光线或“其余参数自动”等内容。JSON 复制同样仅包含已选参数及必要层级；协议版本等技术元信息留在项目文件中，Agent 对接时再按协议封装。

完全没有选择时展示“请选择任意参数后复制”，不要求填写指定模块。完整项目保存与备份不受此裁剪规则限制，仍保留编辑与预览状态。

### 6.2 保存与历史

- 自动保存当前草稿，手动保存命名方案；刷新和重启后可恢复。
- 历史记录必须本地持久化，关闭网页、重启浏览器或重启电脑后仍可查看；不只保存在本次会话内存中。浏览器数据被清理除外，提供备份恢复入口。
- 方案新建、重命名、复制、删除；删除前确认。
- 人物卡、穿搭、姿势、场景和整套方案均可保存为模板。
- 模板应用可按模块选择；覆盖已有值前预览差异，锁定值默认不覆盖。
- 导入导出 JSON；导出 Markdown 创作简报；全量本地数据备份与恢复。
- 导入时校验结构、版本、数值范围和未知资产；失败时不覆盖现有方案。
- 不直接执行导入文件中的脚本或任意资源地址。

#### 6.2.1 历史记录内容与触发

- 复制历史：一键复制成功后自动保存一条，记录时间、来源方案、复制格式、实际复制文本以及当时的完整方案快照。失败不记为复制成功；手动复制降级路径需用户确认后记录。
- 方案版本：手动保存时建立版本；编辑过程中自动保存草稿，并在有实际改动且停止操作一段时间后建立恢复检查点，不为每次按键或滑杆变化生成一条记录。
- 建议自动检查点间隔不少于 30 秒，具体可配置；方案切换前保存未持久化草稿。
- 历史快照同时保留已选参数、选择粒度、锁定状态及必要预览配置，不能恢复后把原本未选字段变成已选。
- 复制内容与快照分开保存：重新复制原文必须得到当时的文本，不因新版本序列化规则变化而悄悄改写。

#### 6.2.2 历史面板

- 提供独立“历史记录”入口，默认按时间倒序展示，区分复制记录、手动版本和自动恢复检查点。
- 支持按方案、时间、记录类型筛选，按方案名和已选参数摘要搜索。
- 每条记录展示时间、方案名、参数摘要、复制格式；支持查看详情、复制当时文本、与当前方案比较、从记录新建方案。
- 恢复旧版本默认新建副本；若覆盖当前方案，先确认并保存当前状态，不能直接丢弃未保存编辑。
- 支持重命名、收藏、单条删除、批量删除；删除前确认。收藏记录不受自动清理影响。
- 支持历史记录随全量备份导出和恢复；单独导出方案时可选择是否包含其历史。

#### 6.2.3 保留策略

- 复制记录与手动保存版本默认不自动删除；自动恢复检查点建议每方案保留最近 100 条，达到上限仅清理未收藏的最旧自动检查点，并在设置中说明。
- 设置页显示记录数量与可获得的本地存储占用信息，支持修改自动检查点保留数量。
- 存储配额不足时明确提示并引导备份、清理或重试，不得显示“已保存”或静默删除手动历史。
- 历史只保存在本地，不上传；本地自动保存不等同于永久备份。

### 6.3 撤销、重做与比较

- 覆盖表单修改、模板应用、随机、换装、拍摄机位修改。
- 连续滑杆拖动合并为一次撤销操作；仅自由观察视角不进入创作历史。
- 支持比较两个已保存方案的参数差异；3D 预览可切换比较，不要求双窗口同时实时渲染。
- 修改方案名等操作不应意外丢失画面配置。

### 6.4 锁定与随机

- 可锁定字段或整个模块。
- 随机只修改明确允许的未锁定维度，且必须遵守服装槽位、动作支撑和道具占用规则。
- 随机结果展示差异，可整体撤销。
- 无可行组合时提示约束原因，不以不合理组合充数。

### 6.5 冲突检查

至少覆盖：

- 一只手同时承担互斥任务。
- 坐卧姿缺少必要支撑物或高度明显不匹配。
- 连体主装与互斥上下装重复占位。
- 不兼容体型、服装、姿势资产组合。
- 要求清晰正脸但人物、头部、相机关系不满足。
- 全身景别但人物明显被裁切。
- 未成年人年龄输入、非法数值或数据结构错误。

分为阻断错误、待确认冲突、建议提示。非法输入阻断；创作冲突允许确认后复制。冲突诊断默认仅在界面显示，不自动加入一键复制内容；用户主动选择“附带诊断”时才附加。自动修复必须先预览改动。

未选择不等于配置错误：例如仅选择坐姿而未选择椅子，可提示预览使用参考支撑物，但不能以“未填场景”阻止复制。检查应区分用户明确指定项之间的矛盾与展示依赖不足。

穿模检测限于已知资产兼容矩阵、绑定约束和基础包围体检查，不承诺通用网格碰撞求解。

## 7. 3D 资产与预览合同

### 7.1 建议首批资产下限

以下为建议验收规模，尚非用户指定数量；开发估算前必须根据可取得资产、授权和适配结果确认。

| 类型         | 建议数量与覆盖                                                           |
| ------------ | ------------------------------------------------------------------------ |
| 人物         | 1 个统一骨骼成年女性基础模特，3 种兼容体型预设                           |
| 发型         | 6 种，覆盖短发、长直、卷发、马尾、盘发等                                 |
| 服装         | 不少于 20 件可渲染单品，覆盖上下装、裙装、连体装、外套、运动、泳装、鞋袜 |
| 饰品附件     | 不少于 10 个，覆盖头、耳、颈、腕、腰和包类                               |
| 姿势         | 不少于 24 个，覆盖站、坐、蹲、跪、卧、行走、运动瞬间                     |
| 场景         | 不少于 6 个低复杂度预设，覆盖影棚、窗边、客厅、城市、海边、自然环境      |
| 支撑物与道具 | 不少于 10 个，覆盖椅、桌、沙发、床、栏杆、书、杯等                       |

不能用只有文字选项、没有对应模型的条目冒充 3D 资产数量。资源清单需记录名称、来源、授权、文件路径、骨骼版本、槽位、材质、兼容姿势与体型。

### 7.2 兼容策略

- 使用统一骨骼与绑定规范；服装跟随姿势，饰品依挂点装配。
- 不保证任意服装与任意体型、姿势自由组合；不兼容项置灰并说明原因。
- 资产缺失时显示占位与提示，原始创作参数不丢失。
- 预览截图只作为参考，不承诺与 AI 输出一致；可导出当前取景图供用户另外使用。
- 所有运行必需资产存储本地，不依赖远程 CDN；首次安装依赖可以联网，安装完成后核心功能可离线使用。

  "camera": {},
  "lighting": {},
  "style": {},
  "story": {},
  "constraints": {},
  "outputIntent": {},

- 创作数据与 3D 展示数据分离：前者描述想要的画面，后者保存模型、材质、骨骼、观察视角等实现细节。
- 项目存档使用完整协议，保留字段状态与预览配置；一键复制使用其稀疏创作参数投影，不输出未选项或无关技术元信息。上面的结构示意用于存档，不代表复制时输出空模块。

- 预留“Agent 适配器”边界，但当前不执行命令、不启动 Agent、不保存 API 密钥。
- 后续接入时通过适配器将统一方案转换为具体 Agent 的协议，不重做表单。

## 9. 技术与本地运行建议

以下为技术建议，并非用户指定技术栈：

- TypeScript + React；Three.js / React Three Fiber 构建 3D 工作区。
- glTF/GLB 资产；本地 IndexedDB 保存方案与模板；JSON 文件负责可迁移备份。
- 提供启动脚本与使用说明，通过 localhost 访问，不以直接双击 HTML 文件作为可靠运行方式。
- 本地服务默认仅绑定回环地址，不对局域网开放。
- 当前无需业务后端；如未来 Agent 需要本机权限，再增加受限本地服务。
- 本地浏览器存储可能被清理，界面提供备份入口，不能声称自动保存等同永久存档。

## 10. 非功能要求

- 目标：桌面 Chrome/Edge 当前稳定版本；其他浏览器兼容性另行验证。
- 1280×800 及以上分辨率可完整操作；面板可折叠。移动端不是本次目标。
- 默认无遥测、无上传人物数据；资源加载错误与本地存储异常有明确提示。
- WebGL 不可用时仍可编辑参数、保存和复制，并提示无法预览。
- 切换资源异步加载，显示进度；避免旧请求覆盖新选择。
- 性能验收前固定测试电脑、渲染分辨率与资源规模；建议目标为常规场景交互不少于 30 FPS、基础表单反馈 100ms 内。
- 支持降低阴影、抗锯齿、景深和贴图质量；长时间操作无明显持续内存增长。
- 图标按钮有文字提示，键盘可操作主要表单；输入框聚焦时不误触场景快捷键。

## 11. 验收清单

1. 可从空白方案完成一套人物、造型、姿势、场景、摄影和光线配置，并复制为完整创作简报。
2. 资产清单内的换装、换发型、配饰装配与姿势切换真实反映在 3D 中。
3. 不支持的细节保留到导出，并明确标注预览限制。
4. 自由观察不改变拍摄机位；主动同步后取景窗口和导出机位一致。
5. 随机、模板应用不覆盖锁定项，冲突有解释且可撤销。
6. 模拟“坐姿缺椅子”“同手两任务”“互斥服装”能够触发对应检查。
7. 当前草稿刷新后恢复；命名方案、模板、备份导入导出均能保留字段状态和锁定信息。
8. JSON 项目文件有合法协议版本，重复导入导出不丢失用户自定义描述；一键复制的稀疏 JSON 不附加技术元信息。
9. 一键复制有成功反馈，权限失败有可用降级方式。
10. 安装完成后断网，资源、预览、保存和复制仍可工作。
11. WebGL 失败不导致整个页面白屏，参数编辑与导出仍可用。
12. 依交付资产兼容矩阵测试，不兼容组合不会被界面冒充为准确预览。
13. 只选择“海边”和“裙装”时，两种复制格式均仅含这两项及必要语义层级，没有默认人物、姿势、颜色、镜头或空模块。
14. 只选大类即可复制；展开分类不会自动选中，选择父类不会自动选中子项。
15. 修改默认预览所需的内部资源不污染创作参数；清除某项后，复制内容立即删除对应项。
16. 只选择坐姿或服装颜色时可独立复制，不因未填其他模块被阻断；用户明确选择“不使用饰品”时该约束正常输出。
17. 复制成功后关闭并重新打开网页，可从历史中找到该记录并复制出完全相同的文本。
18. 从历史恢复时保留“大类已选、子项未选”等状态；默认新建副本，不覆盖当前方案。
19. 历史搜索、收藏、删除、备份恢复可用；自动检查点清理不影响收藏、复制记录或手动版本。
