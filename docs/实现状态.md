# 实现状态与验收范围

2026-11-12 第二次按主人的原话改回：中间必须是可旋转的立体人像，而且要比原来的几何模特更像真人。现在用的是 Lee Perry-Smith 的头部扫描。它能用鼠标拖动或手指旋转、双指缩放。选项只改文字，不改这个模型的姿势和衣服。主界面仍只留下场景、服饰、光线、取景、姿势、人物和一句补充。随机、二十四个姿势库和大量细分项不在主流程里；旧存档里那些项打开后仍会留在「已选」和复制结果中。

## 已可使用

- 全参数目录与部分选择，包括只选大类、只选颜色、只选姿势。
- 简报/JSON 稀疏导出，不夹带默认预览值；锁定与明确排除项正常输出。
- 本地方案、版本、复制历史、检查点、收藏、筛选、恢复副本和全量备份。
- 撤销重做、方向确认、基础创作冲突提示。
- 可旋转的 Lee Perry-Smith 头部扫描，皮肤和五官来自真实扫描。
- 四个文字方向，旁边的小图只作气质参考。
- 本地启动、剪贴板降级、存储异常提示和导入验证。

## 尚未达到原需求完整验收的部分

1. 照片不是参数的实时预览，也没有接生图服务。
2. 主界面不再编辑服装长度、手部任务、机位坐标等细项；数据层仍认识这些字段。
3. 随机组合和模块模板不再放在主流程里。已保存的自定义模板仍可在编辑区底部套用文字。

## 测试方式

`npm test` 验证稀疏参数、级联、锁定、冲突、备份与历史规则。`npm run test:e2e` 在隔离 Chrome 中验证部分选择、参考图不随选项变化、方向确认、历史、撤销和备份。构建执行 TypeScript 检查。

当前项目是已打通核心使用闭环的本地可运行实现，不应被表述为原需求所有资产与验收项均已完成。
