# 实现状态与验收范围

## 已可使用

- 全参数目录与部分选择，包括只选大类、只选颜色、只选姿势。
- 简报/JSON 稀疏导出，不夹带默认预览值；锁定与明确排除项正常输出。
- 本地方案、版本、复制历史、检查点、收藏、筛选、恢复副本和全量备份。
- 撤销重做、模板差异确认、模块模板、受约束随机、基础创作冲突提示。
- 可交互的程序化 3D 人物、服装/发型/饰品轮廓和常用姿态；独立取景与截图。
- 本地启动、WebGL 降级、剪贴板降级、存储异常提示和导入验证。

## 尚未达到原需求完整验收的部分

1. 正式高质量 A+B 数字人、服装资产与统一蒙皮骨骼尚未引入；当前是原创程序化替代。素材预算和美术风格仍需确认。
2. 服装长度和上装等仍有共用属性，尚非每件单品独立的完整属性编辑器；多个款式主要共用基础轮廓。
3. 暂无正式逐资产兼容矩阵和通用穿模检测。只实现显式参数规则、简化支撑物和关节联动，复杂坐卧可能穿插。
4. 部分摄影和环境参数只导出，未模拟景深、天气、真实面料纹理与妆容；界面字段注明其能力。
5. 不含任意骨骼编辑、真人照片级预览、生图或 Agent 调用，这些也不是本次实现应擅自增加的功能。
6. 性能目标尚未在约定的实体设备/资源清单上完成正式压测；浏览器自动化不等于 30 FPS 验收。

## 测试方式

`npm test` 验证稀疏参数、级联、锁定、冲突、备份与历史规则。`npm run test:e2e` 在隔离 Chrome 中验证部分参数复制、跨刷新历史、撤销重做、模板确认、独立观察机位以及 WebGL/剪贴板降级。构建执行 TypeScript 检查。

当前项目是已打通核心使用闭环的本地可运行实现，不应被表述为原需求所有资产与验收项均已完成。
