# portrait-brief 1.0

## 两种数据不可混淆

**创作参数**只包含用户已经选择或主动应用的内容。**项目文件**同时保留 ID、名称、协议版本、锁定、来源、预览机位和时间。全量备份额外包含方案、历史、模板与设置。

### 一键复制的 JSON

```json
{
  "wardrobe": { "category": "裙装" },
  "scene": { "location": "海边" }
}
```

不输出空模块、null、默认年龄、默认姿态、技术版本、文件路径。锁定字段表达为：

```json
{ "scene": { "location": { "value": "海边", "locked": true } } }
```

多选值是字符串数组。明确选择“不使用”与“交由下游决定”仍然输出；它们不是未设置。主动记录的自定义机位以位置、目标点和可选垂直视角输出。

### 项目文件

```json
{
  "schemaVersion": "1.0",
  "id": "唯一 ID",
  "name": "海边创作",
  "fields": {
    "wardrobe.category": {
      "value": "裙装",
      "locked": false,
      "source": "user",
      "state": "specified"
    }
  },
  "camera": null,
  "updatedAt": "2026-11-12T00:00:00.000Z"
}
```

字段目录的权威来源是 `src/catalog.ts`；具体运行时校验见 `schemeSchema`、`databaseSchema`。未选择字段不存入 `fields`。`source` 为 `user / template / random`；`state` 为 `specified / auto / none`。锁定是独立布尔值。

`pose.variant` 为预设姿势补充字段。`camera.position` 表示用户主动记录或描述的机位，实际坐标保存在项目的 `camera` 内。模板可保存这些坐标。

导入只接受受支持的版本、已知字段和合理数值；不执行脚本、不读取任意资源 URL。项目导入默认创建副本。恢复全量备份需确认，因为它替换本地工作区。

## 历史语义

- `copy`：复制成功或用户确认手动复制时记录，包含 `text`、`format` 和独立 `snapshot`。
- `manual`：手动保存正式方案时记录。
- `auto`：停止操作后建立的恢复检查点，以及离开方案前的保护快照。
- 历史原文重新复制时不重新序列化；恢复编辑时创建副本。
- 自动检查点只清理超额且未收藏的自动记录，不清理复制记录或手动版本。

## Agent 接入边界

当前仅复制或下载。未来适配器可包装 `{ protocol: "portrait-brief", version: "1.0", brief: 稀疏参数 }`，但技术包装不出现在当前默认一键复制中。Agent 必须尊重已选与锁定约束，不得把预览默认值误认成用户输入。
